# random-number-picker-en
🇬🇧 Description (English)  🎲 Random Number Picker is a small web app that lets you draw random numbers without repetition, until all numbers have been picked!  🔧 Features:  Choose a maximum number Animated draw with roulette effect Reset button to start over Colorful and responsive design 🖥️ Built using plain HTML, CSS, and JavaScript.
